# Hosted (optional / experimental)

LeGuard v1 is intentionally OSS-first:

- fast local engine (Rust),
- CI integration through CLI + GitHub Action,
- standard artifacts (`json`, `html`, `junit`).

A hosted layer can be added later to:

- retain validation history,
- compare quality trends over time,
- support team collaboration.

The core value of this version remains local-first and CI-native.
